# Aira Lead Mascot Sheet — Round 26 Premium Production Polish

Use case: precise reference-guided production redraw

## Scope

Round 26 is not a concept reset. It preserves Round 25's approved adult IELTS tone, broken signal head, living signal shell with three waveform pulses and a pointed tail, four-module channel, eight action lines, facial-state meanings, props, palette, and transparent sheet composition.

The sole correction is finish: replace rough or inconsistent clip-art anatomy with one disciplined production rig, clean overlaps, balanced negative space, confident curves, and refined facial marks.

## Canonical proportion rig

Head apparatus diameter is the construction unit.

| Part | Canonical measure |
|---|---:|
| Standing height | approximately 5.75 units |
| Signal-shell height | 1.55 units |
| Shoulder / waist width | 0.92 / 0.62 unit |
| Upper arm length / width | 0.72 / 0.20 unit |
| Forearm length / width | 0.66 / 0.17 unit |
| Mitten hand | 0.34 × 0.24 unit |
| Thigh length / width | 1.15 / 0.27 unit |
| Calf length / width | 1.02 / 0.22 unit |

Perspective may foreshorten these measurements by no more than approximately 15%. It may never introduce a different hand, shoe, sleeve, or limb thickness.

## Join and contour rules

- Each shoulder emerges cleanly from the same shell corner.
- Elbows are smooth capsule-to-capsule bends with an intentional navy seam.
- Wrists enter one consistent soft wedge-mitten at its narrow base; hands use one thumb notch and no fingers.
- Hips originate under the shell; knees remain believable trouser-tube bends with clear front/behind overlap.
- Ankles enter the same point of one repeatable cobalt low-wedge shoe.
- Seated and kneeling limbs keep the standing proportions.
- No kink, spike, tangent collision, melted join, hidden extra limb, jagged diagonal, double outline, tiny hook, or accidental merged contour.
