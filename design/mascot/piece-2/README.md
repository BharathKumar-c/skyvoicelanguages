# Piece 2 — Aira Skill Signals

This directory contains the supporting-cast and pose/state system for the four IELTS modules. Aira remains the sole lead mascot; the supporting cast is four faceless, limbless signal objects derived from her module rail.

## Contents

- `piece-2-brief.md` — role hierarchy, cast definitions, state grammar, and acceptance checks
- `prompts/skill-signals-r1.md` — final Round 1 generation prompt
- `source/skill-signals-r1-imagegen.png` — generated transparent source
- `process_piece2.py` — deterministic palette, slicing, and QA processor
- `renders/` — transparent master and individual production renders
- `qa/` — critic-facing visual evidence
- `critic-evidence-r1.md` — verification summary and critic routing
- `round-2-revision-brief.md` — governing Round 2 gap and exit evidence
- `critic-evidence-r2.md` — Round 2 verification and critic routing
- `process_piece2_r2.py` — Round 2 palette, slicing, QA, and publish processor
- `round-3-revision-brief.md` — silhouette-level Round 3 craft correction
- `critic-evidence-r3.md` — Round 3 verification and critic routing
- `process_piece2_r3.py` — Round 3 build entry point using fixed production registration

The web-consumable copies live in `apps/web/public/mascot/skill-signals/`.
